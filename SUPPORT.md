# Optional support

The Session Cost Skills repository is free and MIT-licensed. Anyone may install, run, modify, and redistribute the skills under the terms of the [MIT License](LICENSE).

No purchase is required for:

- Cline usage
- MCode usage
- Interactive dashboards
- JSON output
- Local session accounting
- Cline account mode
- MCode rate coverage

## Optional Gumroad support

A Gumroad listing may provide voluntary paid support for:

- Installation and compatibility help
- Investigating a confirmed bug
- Runtime migration guidance
- Sponsored feature development
- Priority response for a bounded support request

Paid support does not remove the MIT rights in the public source. It does not license the support provider to relicense or rebrand the public project.

Support scope, response expectations, and prices should be published on the Gumroad product page before purchase. Keep the public GitHub documentation usable without purchasing support.
