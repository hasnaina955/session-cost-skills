Internal optional-support launch checklist

Maintainer-only launch guidance. This file is not a customer artifact and must not override the repository MIT License.

Non-negotiable terms

  • Keep the MIT license and copyright notice in every source archive and customer artifact.
  • Sell optional support or sponsored maintenance, never access to functionality already published under MIT.
  • Do not relicense, rebrand, or remove attribution from the public project.
  • Publish price, scope, delivery period, response target, cancellation terms, and refund terms only after qualified legal review.
  • Keep the public GitHub documentation complete and usable without a purchase.

Correct customer payload

session-cost-skills-vX.Y.Z/
  cline-skill/       contents of adapters/cline/skill/
  mcode-skill/       contents of adapters/mcode/skill/
  LICENSE
  README.md
  SUPPORT.md
  CHANGELOG.md

Generate archives only through the release packaging script. Do not include the private Git history, reports, databases, logs, or settings.

Clean Windows installation

Cline

Copy the contents of cline-skill/ to:
  %USERPROFILE%\.cline\skills\session-cost\

Confirm:
  %USERPROFILE%\.cline\skills\session-cost\SKILL.md

MiniMax Code

Copy the contents of mcode-skill/ to:
  %USERPROFILE%\.minimax\skills\session-cost\

Confirm:
  %USERPROFILE%\.minimax\skills\session-cost\SKILL.md

Verification before publication

  1. Run npm run verify and the complete runtime/OS CI matrix.
  2. Build a customer payload from the release script and record checksums.
  3. Install both skills into clean Windows profiles and confirm the exact SKILL.md paths above.
  4. Exercise one local report, one dashboard, normalized JSON, and Cline account mode when applicable.
  5. Scan the payload for credentials, databases, generated reports, logs, private source files, and mojibake.
  6. Verify the MIT license is byte-for-byte identical to the repository license.

Support and privacy copy

Use SUPPORT.md as the canonical troubleshooting, privacy, and support-contact text. Public defect reports belong in the repository issue tracker. Security reports follow SECURITY.md.

Do not promise uptime, custom-provider work, deleted-data recovery, or a response time until that scope and period are explicitly purchased and legally reviewed.

Commercial checklist

  • Qualified legal review completed
  • Final price and offering page approved
  • Scope, delivery period, and response target published
  • Cancellation and refund terms published
  • Support contact tested
  • Clean customer payload built and checksummed
  • Both clean Windows installs verified
  • MIT license retained in every archive
