5. Product description

Session Cost Skills is a privacy-conscious usage and cost reporting system for Cline and MiniMax Code.

Track token usage, cached input, provider rates, billing classifications,
subagent activity, session comparisons, and account usage limits.

Included:
• Cline local session and account analytics
• MiniMax Code provider-rate accounting
• Interactive offline HTML dashboards
• JSON output for automation
• No developer-owned server

Cline and MiniMax Code use different ledgers and billing rules. Each edition
intentionally preserves its runtime-specific accounting logic.

6. Installation

Cline

1. Close Cline.
2. Extract the bundle.
3. Copy cline-session-cost into:
   %USERPROFILE%\.cline\skills\
4. Confirm:
   %USERPROFILE%\.cline\skills\session-cost\SKILL.md
5. Start a new Cline session.
6. Run:
   /session-cost

MiniMax Code

1. Close MiniMax Code.
2. Extract the bundle.
3. Copy mcode-session-cost into:
   %USERPROFILE%\.minimax\skills\
4. Confirm:
   %USERPROFILE%\.minimax\skills\session-cost\SKILL.md
5. Start a new MiniMax Code session.
6. Run:
   /session-cost

7. Privacy and compatibility

Local reports read runtime data already stored on the computer. Optional Cline account mode uses the customer’s own Cline authentication and read-only API access. The product does not print or store credentials and does not use a developer-owned server.

Runtime updates may change ledgers, model identifiers, rate catalogs, or API response formats. The product reports unknown or unpriced data rather than guessing.

Requirements:
• Windows 10 or Windows 11
• Cline CLI or MiniMax Code CLI
• Node.js 22.5 or newer
• Internet access only for Cline account mode
• Valid Cline authentication for Cline account mode
