Session Cost Skills

Optional support onboarding pack for the free, MIT-licensed Cline and MiniMax Code skills.

Free software

The skill source is free under the MIT license. Payment is optional and does not unlock any software feature.

Repository: https://github.com/hasnaina955/session-cost-skills

Requirements

  • Windows 10 or Windows 11
  • Node.js 22.5 or newer
  • Cline CLI or MiniMax Code CLI
  • Cline account authentication for live account mode

Cline install

1. Close Cline.
2. Copy the Cline skill folder into:
   %USERPROFILE%\.cline\skills\session-cost\
3. Confirm SKILL.md exists.
4. Start a new Cline session.
$SessionCost = "$env:USERPROFILE\.cline\skills\session-cost\scripts\session-cost.mjs"
node $SessionCost
node $SessionCost --account
node $SessionCost --dashboard

MiniMax Code install

1. Close MiniMax Code.
2. Copy the MCode skill folder into:
   %USERPROFILE%\.minimax\skills\session-cost\
3. Confirm SKILL.md exists.
4. Start a new MiniMax Code session.
$SessionCost = "$env:USERPROFILE\.minimax\skills\session-cost\scripts\session-cost.mjs"
node $SessionCost
node $SessionCost --rates
node $SessionCost --dashboard

What the support purchase covers

  • Installation and compatibility assistance
  • Investigating a confirmed bug
  • Runtime migration guidance
  • Priority help for a bounded support request
  • Sponsored development when separately agreed

Support does not include credentials, API keys, private transcripts, custom reverse engineering, or guaranteed third-party API availability.

Privacy

Local mode reads runtime data already on your computer. Cline account mode uses your own Cline authentication and read-only API requests. Never send API keys, OAuth tokens, secrets.json, or private session transcripts when requesting support.

FAQ

Is the software paid?

No. The source is free and MIT-licensed. Support is optional.

Why is there a Gumroad listing?

It funds maintenance, compatibility work, documentation, and sponsored development.

Does support change the license?

No. The public MIT license remains in effect.

What if my report says rate unknown?

The skill reports the uncertainty instead of guessing. Run the MCode rate coverage command and refresh rates if appropriate.
