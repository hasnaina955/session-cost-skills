2. Requirements

  • Windows, Ubuntu, or macOS, plus the corresponding Cline CLI or MiniMax Code CLI.
  • Node.js 22.13.0 or newer. This is the repository support floor; the earlier introduction of node:sqlite is not the project support promise.
  • Bun 1.4.2 or newer is optional and CI-tested for adapter tests and CLI smoke checks. Use the reference Node.js runtime if a Cline or MCode integration issue occurs.
  • No npm install or Python dependency is required for the current verification suite.

3. Install to the exact skill paths

Copy the contents of each adapter source directory. The final directory must be named session-cost.

AdapterWindows destinationLinux/macOS destination
Cline%USERPROFILE%\.cline\skills\session-cost\$HOME/.cline/skills/session-cost/
MCode%USERPROFILE%\.minimax\skills\session-cost\$HOME/.minimax/skills/session-cost/

Windows from a source checkout

$Repo = "C:\path\to\session-cost-skills"
$ClineSkill = "$env:USERPROFILE\.cline\skills\session-cost"
$MCodeSkill = "$env:USERPROFILE\.minimax\skills\session-cost"

New-Item -ItemType Directory -Force $ClineSkill | Out-Null
New-Item -ItemType Directory -Force $MCodeSkill | Out-Null
Copy-Item -Path "$Repo\adapters\cline\skill\*" -Destination $ClineSkill -Recurse -Force
Copy-Item -Path "$Repo\adapters\mcode\skill\*" -Destination $MCodeSkill -Recurse -Force

Linux or macOS from a source checkout

mkdir -p "$HOME/.cline/skills/session-cost" "$HOME/.minimax/skills/session-cost"
cp -R adapters/cline/skill/. "$HOME/.cline/skills/session-cost/"
cp -R adapters/mcode/skill/. "$HOME/.minimax/skills/session-cost/"

From a release archive

A release archive contains staging folders named cline-session-cost/ and mcode-session-cost/. Copy each folder’s contents into the corresponding session-cost/ destination; do not expect the wrapper name to become the installed skill name.

Clean-install assertion (PowerShell)

$ClineSkill = "$env:USERPROFILE\.cline\skills\session-cost"
$MCodeSkill = "$env:USERPROFILE\.minimax\skills\session-cost"

if (-not (Test-Path "$ClineSkill\SKILL.md")) { throw "Cline install is incomplete" }
if (-not (Test-Path "$MCodeSkill\SKILL.md")) { throw "MCode install is incomplete" }

node "$ClineSkill\scripts\session-cost.mjs" --help
node "$MCodeSkill\scripts\session-cost.mjs" --help

Restart the CLI or begin a new session after installing so it discovers the skill.

4. Run the skills

# Cline
node "$env:USERPROFILE\.cline\skills\session-cost\scripts\session-cost.mjs"
node "$env:USERPROFILE\.cline\skills\session-cost\scripts\session-cost.mjs" --account
node "$env:USERPROFILE\.cline\skills\session-cost\scripts\session-cost.mjs" --dashboard

# MCode
node "$env:USERPROFILE\.minimax\skills\session-cost\scripts\session-cost.mjs"
node "$env:USERPROFILE\.minimax\skills\session-cost\scripts\session-cost.mjs" --rates
node "$env:USERPROFILE\.minimax\skills\session-cost\scripts\session-cost.mjs" --refresh-rates
node "$env:USERPROFILE\.minimax\skills\session-cost\scripts\session-cost.mjs" --dashboard

Use --session <id> when automatic selection is ambiguous. Date, provider, model, JSON, comparison, and output options are listed by each CLI’s --help.

5. Optional standing configuration

Both CLIs read, but do not rewrite, these optional files:

  • %USERPROFILE%\.cline\session-cost.json
  • %USERPROFILE%\.minimax\session-cost.json
{
  "standingSummary": true,
  "includeChildren": true,
  "defaultFormat": "compact",
  "warnOnCacheRateBelow": 0.6
}

Command-line selection still takes precedence where explicitly supported. Keep the configuration free of credentials.

The project has no developer-owned telemetry or accounting server.

7. Cline account credentials

--account resolves credentials in this order:

  1. CLINE_API_KEY
  2. A non-expired OAuth access token in data/settings/providers.json for cline or cline-pass
  3. Legacy data/secrets.json apiKey

The credential is sent only as authorization for the read-only Cline API request. It is not printed or embedded in a dashboard. Re-authenticate with cline auth --provider cline if it is expired or invalid.

8. Accounting behavior that differs by runtime

TopicClineMCode
Input tokensinputTokens includes cached prompt tokens; fresh input is the remainder after cache read/write.input_tokens is fresh input and excludes cache reads/writes.
CostUses Cline-recorded per-call metrics.cost.Calculates cost from mirrored provider rates.
Cache-write billingReports recorded cache-write tokens/cost without applying Cline’s formula to MCode.Uses a published cache-write rate. A missing rate is unknown, never an assumed zero; positive cache writes then make the call partial/unknown. StepFun step-5-preview explicitly uses its input rate.
--include-childrenRecursively includes all descendant subagent sessions.Includes direct child sessions only in version 0.2.0.
Unknown pricingMissing recorded cost is reported, not guessed from an external table.Unknown provider/model rates are excluded from the priced total and named.

Never subtract MCode cache reads from input_tokens; that would apply Cline’s convention to the wrong ledger.

9. Troubleshooting

SymptomCheck
Skill is not discoveredConfirm the file is exactly …\.cline\skills\session-cost\SKILL.md or …\.minimax\skills\session-cost\SKILL.md, then start a new CLI session.
node:sqlite is unavailableRun node --version; upgrade to Node.js 22.13.0 or newer.
Cline account unauthorizedRun cline auth --provider cline, then retry. Do not paste the credential into a report.
MCode says a rate is stale or unknownRun --rates. Use --refresh-rates only when network access and a writable installed skill are acceptable.
MCode refresh cannot writeRestore write permission or install to a user-writable skills directory. If any source fails, a previous valid table is retained in full and no refresh file is written.
Subagent spend is missingUse --include-children; Cline includes all descendants, while MCode 0.2.0 includes direct children.
Unexpected session selectedUse --list and then --session <id>.
Text renders incorrectlySave the HTML as UTF-8. Both HTML documents in this repository declare UTF-8 and are checked by CI.
